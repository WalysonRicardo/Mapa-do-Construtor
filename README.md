# Mapa do Construtor

Planta 2D interativa da escola, feita para ser **projetada no chão** da sala de aula. As crianças usam bloquinhos para montar os prédios e espaços da escola em cima da projeção.

## Como usar

Abra o `index.html` no navegador (ou a página do GitHub Pages) e ligue o projetor.

- **Modo projeção**: esconde os controles. A tecla **H** mostra/esconde de novo.
- **Visual "Só contornos"**: fundo preto e linhas brancas, o mais nítido para montar os blocos.
- **Girar / Espelhar / Zoom**: para encaixar o mapa no espaço do chão (espelhar ajuda com projetor de teto).
- **Nomes dos espaços**: escreva na lista lateral; o nome aparece na hora no chão.
- **Editar espaços**: mova e redimensione as áreas para ajustar a planta à escola real.
- **Alunos**: crianças vistas de cima andando pela escola, com os modos *Passeio*, *Recreio* e *Hora da aula*.
- **Guardar**: tudo fica salvo no navegador; use "Copiar configuração" para levar para outro computador.

Arquivo único (HTML + CSS + JavaScript), sem instalação e sem coleta de dados.
